# 📚 AI Study Assistant

AI Study Assistant is an AI-powered educational web application built with Python, Streamlit, Gemini API, and gTTS. It helps students generate clean study notes from uploaded note images, convert generated notes into audio, and create quizzes based on the uploaded study materials.

This tool is designed to improve productivity and make studying more efficient using multimodal AI.

## 🚀 Features

- Upload up to 3 study note images
- Generate short and clear study notes using Gemini API
- Convert generated notes into audio using gTTS
- Generate quizzes based on selected difficulty level
- Download generated notes as a text file
- Download generated quizzes as a text file
- Simple and interactive Streamlit user interface
- Error handling for invalid images and missing inputs

## 🛠️ Tech Stack

- Python
- Streamlit
- Gemini API (Google AI)
- Google GenAI SDK
- PIL (for image handling)
- gTTS


## 🧠 Project Type

This project is an AI-powered educational web application. It is not only a chatbot because it does not mainly work through conversation. Instead, it works as a study assistant tool that processes uploaded study images and generates notes, quizzes, and audio output.

## ⚙️ How It Works

1. The user uploads note images.
2. The app sends the images to Gemini API.
3. Gemini generates student-friendly study notes.
4. The generated notes are converted into audio using gTTS.
5. The app generates quizzes based on the selected difficulty level.
6. The user can view and download the generated notes and quizzes.
